# PawFind — React.js Activity 1

A React + pure CSS redesign of the original PawFind lost-and-found dog website.

## Technologies
- React.js
- JavaScript
- Pure CSS
- Vite

No Bootstrap, Tailwind CSS, Material UI, or other UI/CSS frameworks are used.

## Features
- React component-based layout
- Home, About, Dog Feed, and Contact sections
- React state for search, filters, modal details, navigation, and form submission
- Responsive pure CSS design
- Dog search by name, breed, location, or color
- Lost/Found filtering
- Reusable DogCard component
- Existing PawFind images retained from the original project

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite address shown in the terminal.

## Build for production

```bash
npm run build
```
